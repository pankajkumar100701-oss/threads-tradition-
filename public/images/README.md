# Campaign images

Drop generated images here, named after their slot (`.jpg`, `.png`, `.webp` or `.avif`),
then restart `npm run dev`. Any slot without a file uses its fallback photo from `commons/`.
Keep every shoot to Himachali dress: pattu, dhatu, chola, luanchari, koti, topi, thepang and silver.
